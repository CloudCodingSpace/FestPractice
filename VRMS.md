Project: Console-based Vehicle Rental Management System

Goal:
Build a Java application where users can rent and return vehicles.

Features:
- Vehicle management (Car, Bike, Truck)
- Customer management
- Rent / Return vehicles
- Search vehicles
- Sort vehicles
- Store data in files
- Handle invalid input using exceptions
- Use OOP properly
- Use Java Collections (ArrayList, HashMap, Queue, Stack)
- Maintain rental history
- Calculate total revenue

Purpose:
Practice Java syntax, OOP, Collections, File I/O, String handling, Exception handling and basic algorithms in one project.
